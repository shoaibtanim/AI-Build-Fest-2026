1. Adaptive AI Tutor

অ্যাডাপ্টিভ এআই টিউটর

What is it? An intelligent tutoring system that understands a student’s learning level and adjusts lessons, quizzes, and explanations accordingly.
এটি কি? একটি ইন্টেলিজেন্ট টিউটরিং সিস্টেম যা শিক্ষার্থীর লার্নিং লেভেল বুঝতে পারে এবং সেই অনুযায়ী লেসন, কুইজ ও ব্যাখ্যা পরিবর্তন করে।

Example / উদাহরণ:

If weak in math → easier explanations. If performs well → harder questions. If makes mistakes → provides hints.

গণিতে দুর্বল হলে সহজ ব্যাখ্যা দেবে, ভালো করলে কঠিন প্রশ্ন ছুঁড়ে দেবে এবং ভুল করলে দরকারি হিন্টস (Hints) প্রদান করবে।

Key Features & Future Scope:

Smart Quiz / কুইজ
Hint System / হিন্ট
Bangla Voice Support
Emotion Detection
Tech Stack: Python Flask, OpenAI API, React, MySQL

4. Multimodal Learning Assistant

মাল্টিমোডাল লার্নিং অ্যাসিস্ট্যান্ট

Why is it powerful? Not everyone learns via text. Some prefer voice, others prefer visuals. This assistant combines text, voice, images, and video.
এটি কেন শক্তিশালী? সবাই শুধু লেখা পড়ে শেখে না। কেউ শুনে, কেউ দেখে বোঝে। এই অ্যাসিস্ট্যান্ট টেক্সট, ভয়েস, ইমেজ ও ভিডিও একসাথে ব্যবহার করে কাজ করে।

Example / উদাহরণ: Student uploads a photo of a math problem → AI reads the image (Google Vision API) → Explains solution via voice (Whisper Speech Model).

শিক্ষার্থী গণিতের ছবি আপলোড করলে এআই ইমেজ রিড করবে এবং ভয়েসের মাধ্যমে সমাধান বুঝিয়ে দেবে।
